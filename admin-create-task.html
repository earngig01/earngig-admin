Create Task

Create an EarnGig task for members to complete. Admin-created tasks do not require payment from the admin wallet.

Basic Task Information

Enter the basic information members will see.

Question

Enter the question the member must answer.

This answer is stored for admin verification and is not shown to members.
Example: "Answer in one or two sentences."
Members will see the question and submit their answer. Their answer will be stored in the task attempt for admin review.

Social Media Task

Select the platform and action the member must complete.

The member will submit a screenshot/photo as proof, together with the URL of the social account used for the action. Admin verification is required before the reward is credited.

Photo Proof

This task requires the member to upload photo or screenshot proof.

Photo-related submissions always require admin verification. Uploading a photo does not automatically earn the reward.

Verification

Choose how the completed task will be verified.

Social media tasks use Photo + Account URL. Photo tasks use Photo / Screenshot. Riddles use Admin Verification.

Task Link

Add the URL the member needs to visit, when applicable.

Example: TikTok profile, Instagram post, YouTube channel, website or survey.
